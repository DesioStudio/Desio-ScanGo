# 部署指南

本文档面向**想在自己电脑上运行 Desio ScanGo** 的人。照着做一遍大约需要十分钟，其中 iPhone 装证书的部分只需要做一次。

> 只想看界面、不需要手机真机扫码的话，可以跳过证书那一节，程序会自动以 HTTP 方式运行，功能不受影响。

---

## 开始之前：为什么要自己生成证书

浏览器有一条硬性规定：**只有通过 `https://` 或 `localhost` 打开的页面，才允许调用摄像头**。局域网地址（`http://192.168.x.x`）属于非安全来源，iPhone 上 `navigator.mediaDevices` 直接是 undefined，扫码功能根本不会启动。

所以必须用 HTTPS，而 HTTPS 需要证书。证书不能由别人代劳生成好再拷给你——**证书里绑定了签发时的局域网 IP**，每台机器的 IP 不一样，拷贝过来的证书在另一台机器上会被浏览器拒绝。

因此正确做法是：在你自己的电脑上，用你的 IP，现场生成。这也是为什么从网上下载别人打包好的安装包，在 iPhone 上用不了摄像头。

好在这只需要一条命令。

## 一、准备环境

| 项目 | 要求 | 检查命令 |
| --- | --- | --- |
| 系统 | Windows（键盘输入模拟基于 Windows） | — |
| Node.js | 20 或更高 | `node -v` |
| openssl | 用于生成证书 | `openssl version` |
| 网络 | 手机与电脑在同一个 WiFi | — |

**没有 openssl？** 安装 [Git for Windows](https://git-scm.com/download/win) 就会自带（位于 `Git\mingw64\bin\openssl.exe`）。证书脚本会自动去找它，不需要额外配置 PATH。

**防火墙**：首次启动时 Windows 可能弹出网络访问请求，选择「允许访问」。如果手机始终打不开页面，去 Windows 防火墙里确认 Node.js 和 Electron 的**入站**连接没有被拦（公用网络下默认可能拦截）。

## 二、获取代码

```bash
git clone <仓库地址>
cd Desio-ScanGo
```

## 三、安装依赖

```bash
npm install
```

## 四、生成 HTTPS 证书

```bash
npm run dev:cert
```

成功后会输出类似：

```text
[dev:cert] 生成本地 CA...
[dev:cert] 为 192.168.1.23 签发服务器证书...

证书已生成:
  服务器证书  certs/server-cert.pem
  服务器私钥  certs/server-key.pem
  根证书      certs/ca.pem  <- 把这个装到 iPhone
```

产物都放在 `certs/` 目录（已被 git 忽略，不会提交到仓库）。证书有效期 825 天——这是 iOS 对服务器证书的硬性上限。

**换 WiFi 或路由器重新分配 IP 之后，需要重跑一次这条命令**，然后 iPhone 上重新装一次证书。

---

## 五、启动

```bash
npm run dev
```

桌面端窗口会自动打开。启动的是两个服务：

| 服务 | 地址 | 说明 |
| --- | --- | --- |
| 手机端页面 | `https://<你的IP>:5173` | 扫码网页 |
| 桌面端扫码服务 | `https://<你的IP>:<随机端口>` | 二维码指向的就是它 |

**扫码服务的端口每次启动都是随机的**，所以不要保存旧链接，每次用桌面端窗口里显示的那个二维码。

## 六、iPhone 安装证书（只需做一次）

### 1. 下载证书

用 iPhone 的 Safari 访问（端口看桌面端上显示的那个）：

```text
https://<你的IP>:<端口>/ca.pem
```

Safari 会提示「无法验证服务器身份」，点「详细信息」→「访问此网站」。

### 2. 安装描述文件

弹出安装提示后点「允许」，按引导完成安装。

### 3. 手动开启信任

```text
设置 → 通用 → VPN与设备管理 → 安装描述文件
设置 → 通用 → 关于本机 → 证书信任设置 → 打开 "Desio ScanGo Dev CA"
```

**第 3 步最容易漏。** 只装了描述文件、没开信任开关的话，Safari 依然会拒绝连接，表现为页面打不开或摄像头无反应。

---

## 七、Android 说明

两个选择：

- **推荐**：跟 iOS 一样走 HTTPS。用 Chrome 访问 `https://<你的IP>:<端口>/ca.pem` 下载证书并安装即可
- **临时方案**：地址栏打开 `chrome://flags/#unsafely-treat-insecure-origin-as-secure`，填入 `http://<你的IP>:5173`，重启浏览器

Android 上扫码成功会同时震动并播放提示音；iPhone 不支持震动接口，只有提示音。

## 八、验证清单

全部打勾说明部署成功：

- [ ] `npm run dev` 启动后桌面端窗口显示「运行中」，右侧有二维码

- [ ] 点「开始扫码」，允许摄像头权限后能看到实时画面
- [ ] 扫一个商品条码，桌面端历史列表里出现记录
- [ ] 光标点到记事本，再扫一次，条码数字被自动键入

## 九、故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 手机上打不开二维码里的地址 | 不在同一 WiFi，或防火墙拦截 | 确认 IP 前三位一致；放行 Node.js / Electron 入站 |
| 地址栏是 `http://` 开头 | 证书没生成成功，回落到了 HTTP | 检查 `openssl version` 是否可用，重跑 `npm run dev:cert` |
| 页面能开，点开始扫码没反应 | 非安全来源，或证书未开信任 | 页面会提示「当前不是安全来源」；确认信任开关已打开 |
| 换了个 WiFi 之后就不行了 | 证书绑定的是旧 IP | 重跑 `npm run dev:cert`，iPhone 重装证书 |
| 扫码结果出现在别的应用里 | 键盘输入会打到当前焦点窗口 | 先点目标输入框再扫；或取消勾选「将扫码结果输入到当前窗口」 |
| 桌面端二维码位置空白 | 服务刚启动，状态未广播 | 等待几秒；持续空白则重启 `npm run dev` |
| `npm run dev:cert` 报找不到 openssl | 系统没有 openssl | 安装 Git for Windows |

## 十、打包成安装包（可选）

```bash
npm run package
```

会在 `release/` 下生成 Windows 安装包 `Desio-ScanGo-Setup.exe`。

> **已知限制**：打包后的安装包目前不带证书，因此以 HTTP 运行，**iPhone 上无法调用摄像头**。需要手机在 iOS 上可用时，请按本文档以源码方式运行。
